## 結論

Age v3 在 leakage-free internal split 的改善沒有外推到 frozen E2E benchmark。
v3 優於 v1，但落後 v2；目前不能將 v3 升為部署模型。27px 只有 15 個
Conditional 樣本，仍是 detector-gated，不應用來選 Age 模型。

v3 internal validation 使用固定 34px resize-and-pad，而實際 VAC E2E 是將
YuNet margin crop 直接 resize 至 64x64。這個 domain/preprocessing gap 是下一輪
最優先驗證的 hypothesis；必須在不查看 benchmark labels 的前提下，用 training/
validation 資料建立 runtime-faithful crop pipeline。
